# Security policy

This is an experimental proof of concept, not production-ready compliance software. Do not rely on its output as a certification or use it to process secrets.

Report vulnerabilities privately via GitHub's **Report a vulnerability** feature if enabled; otherwise contact repository maintainers privately rather than opening a public issue with exploit details.

Supported versions: current main only during pre-1.0 development.

Security boundaries: JSON inputs are untrusted, evidence provenance is unverified, and reviewers are not authenticated.
