# Delivery roadmap

- **PoC 0.1.0:** CLI, fictional demo catalogue, explicit policy, JSON report, tests.
- **0.2:** Official pinned ASVS 5.0.0 catalogue ingestion and robust schema validation.
- **0.3:** SARIF, JUnit, CycloneDX adapters with provenance and immutable evidence IDs.
- **0.4:** SQLite, evidence freshness, environments, N/A applicability, conflict resolution.
- **0.5:** GitHub Actions and Azure DevOps adapters; SonarQube and Dependency-Track.
- **0.6:** Human review API, reviewer identities, rationale, audit trail and re-open triggers.
- **1.0:** Web/desktop UI, signed exports, comprehensive tests, release and security hardening.

Comprehensive catalogue support is not the same as comprehensive automatic verification.
